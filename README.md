# 송쌤과학 GIF 스튜디오 V1.0

여러 이미지 또는 공유 화면을 움직이는 수업용 GIF로 만드는 교사용 도구입니다. 디자인 시스템 V1.0의 A 작업대형, 호박색 계열, 밝은·어두운 테마를 적용했습니다.

## 실행하기

**이미지 제작:** `index.html`을 PC Chrome에서 열면 됩니다. 인터넷이 없어도 편집·GIF 생성은 작동하며 기기의 기본 글꼴을 사용합니다. 별도 설치나 빌드는 필요하지 않습니다.

**화면·탭·영역 녹화:** Windows와 Mac에서 같은 웹사이트를 사용합니다. 화면 공유를 제공하는 PC Chrome·Edge와 HTTPS 또는 localhost를 권장합니다. Python3가 설치돼 있다면 아래 실행 도우미를 더블클릭해 localhost 서버와 브라우저를 열 수 있습니다.

- Windows: `로컬실행.bat` — `py -3`를 먼저 확인하고, 없으면 `python`을 사용합니다.
- macOS: `로컬실행.command`.

기본 브라우저에 화면 공유 기능이 없으면 실행 창에 표시된 주소를 Chrome·Edge에서 여세요. Windows 실행 도우미와 Windows·Edge의 실제 공유 선택창·권한 동작은 아직 검증하지 않았습니다.

이 폴더에서 터미널로 직접 실행할 수도 있습니다.

```sh
python3 "_작업자료/serve.py"
```

서버는 이 폴더를 `127.0.0.1`에서만 제공하며 터미널의 Ctrl+C로 종료합니다. 서버 실행 중에만 localhost 주소가 열립니다. 소스 저장소: [songsamscience/gif-studio](https://github.com/songsamscience/gif-studio). 홈페이지 호스팅·사이트 목록 등록은 하지 않았습니다.

## 이미지 → GIF

1. **이미지 불러오기**로 PNG·JPEG·정지 WebP를 여러 장 선택합니다. 끌어 놓기와 이미지 붙여 넣기도 가능합니다. **예제로 사용해 보기**는 확산 실험 도식4장을 실제 프레임으로 추가합니다.
2. **프레임 정리**에서 순서·선택·복제·삭제를 조절합니다. 썸네일을 끌거나 앞/뒤 이동 단추를 사용하세요. Shift는 범위, Ctrl/Cmd는 여러 장 선택입니다.
3. **시간·재생**에서 전체 또는 선택 프레임의 표시 시간을 정하고 순서대로·거꾸로·왕복, 한 번·무한·총 횟수를 선택합니다.
4. **자르기·크기**에서 출력 크기·사진 맞추기·배경색·공통 자르기 영역을 정합니다. 배율은 미리보기에만 적용됩니다.
5. **글자·설명**에서 한글 자막·화살표·강조 사각형·불투명 가리기를 현재·선택·모든 프레임에 적용합니다.
6. **GIF 만들기** 후 실제 결과의 크기·프레임 수·시간·용량을 확인하고 **GIF 저장**을 누릅니다. 파일명은 프로젝트명과 날짜입니다.

이미지 이어 붙이기는 여러 장을 시간 순서로 연결하는 움직이는 GIF입니다. 가로·세로로 한 장의 PNG를 만드는 기능은 다음 버전의 확장 후보입니다.

## 화면·창·탭 → GIF

1. 녹화할 화면이나 실험 사이트를 먼저 엽니다.
2. **화면·창 녹화** 또는 **브라우저 탭 녹화**에서 **녹화 화면 선택**을 누르고 브라우저 공유 선택창에서 대상을 직접 선택합니다. 전체 화면·창·탭 가운데 실제 선택 항목은 브라우저가 결정합니다.
3. 라이브 미리보기를 확인하고 **녹화 시작**을 누릅니다. 시작 대기3초 또는 바로 시작, 최대15초 또는30초를 선택할 수 있습니다.
4. 일시정지·계속 녹화·녹화 정지를 사용합니다. 브라우저의 공유 중지도 정상 종료로 처리합니다.
5. 정지 후 시작·끝 시간과 추출 FPS를 정하고 **구간을 프레임으로 가져오기**를 누릅니다. 기존 프레임 뒤에 추가됩니다.
6. 자르기·설명을 편집하고 GIF를 만듭니다.

macOS는 브라우저의 화면 녹화 권한을 요구할 수 있습니다. 권한 거절·공유 취소 후에는 화면을 다시 선택하세요. 녹화 중 다른 도구로 이동하기 전에 정지 또는 공유 종료를 누릅니다. URL만 입력해 외부 사이트를 자동 녹화하는 기능은 제공하지 않습니다.

공유 스트림을 MediaRecorder로 기록하고 정지 후 프레임을 추출합니다. 실제 로컬 탭 녹화는 검증했으며, 사용자 화면·창의 수동 권한 절차와 엄격한 배경 탭 상태는 별도 확인이 필요합니다. 범위는 `검증결과.md`에 있습니다.

## 공유 화면 영역 녹화

1. **공유 화면 영역 녹화**(단축키0)에서 공유할 화면을 선택합니다. 브라우저 선택창에서 **전체 화면·창·탭** 중 녹화할 대상을 직접 고르세요. 전체 화면을 우선 제시하도록 요청하지만, 앱이 선택을 강제하지 않습니다.
2. 사이트의 공유 미리보기에서 사각형을 드래그하거나 X·Y·너비·높이를 입력합니다. 아래 **선택 영역 미리보기**에서 GIF에 담길 부분을 확대해 확인하고 **영역 확정**을 누릅니다.
3. **선택 영역 녹화 시작**을 누르면 확정한 범위가 고정됩니다. 범위나 숫자를 변경하면 다시 **영역 확정**을 눌러야 녹화를 시작할 수 있습니다. 녹화 중에는 범위를 바꾸지 않습니다.
4. 녹화를 정지한 뒤 구간·FPS를 고르고 **구간을 프레임으로 가져오기**를 누릅니다. 지정한 부분만 편집기에 추가되며, 설명을 편집한 뒤 GIF로 저장합니다.

브라우저 선택창은 공유 대상을 고르는 단계이고, 사각형 범위는 이어지는 사이트 미리보기에서 지정합니다. 웹사이트는 GIPHY Capture처럼 운영체제 바탕화면 위에 선택 테두리를 띄우지 않습니다. **전체 영역**으로 선택을 초기화할 수 있습니다.

좌표는 브라우저가 공유한 원본 영상의 픽셀 기준이며 출력 배율과 구분합니다. 녹화 도중 공유 대상·창 크기를 바꾸면 영역이 달라질 수 있습니다. 선택 영역만 GIF로 만들지만 공유 전체 영상은 이 기기에 임시 기록합니다. 새 공유·새 작업에서는 영역을 초기화하고, 추출 취소 시에는 녹화와 영역을 유지합니다.

## 한 장씩 캡처

**한 장씩 캡처 → 캡처 화면 선택**으로 공유를 시작합니다. 원하는 순간마다 **현재 화면 캡처**를 누르면 프레임이 추가됩니다. **공유 종료** 후 순서·시간·설명을 편집해 저장하세요. 브라우저가 허용한 공유 화면을 사용하며 다른 앱에서 작동하는 전역 캡처 단축키는 없습니다.

## 기본값·한도

| 항목 | 값 |
| --- | --- |
| 이미지 표시 시간 | 500ms, 20~60,000ms 조절 |
| 작업 캔버스 | 800×450px, 비율 유지 + 여백 |
| 녹화 추출 | 10FPS, 5·10·15·20FPS 선택 |
| 녹화 시간 | 기본 최대15초, 선택 시 최대30초 |
| 작은 용량 / 균형 / 선명함 | 가로480·5FPS·64색 / 800·10FPS·128색 / 1024·15FPS·256색 |
| 프레임 수 | 최대600장, 왕복 재생의 추가 프레임 포함 |
| 출력 긴 쪽 | 최대1280px |
| 이미지 파일 / 임시 녹화 | 장당50MB / 녹화128MiB |
| 실행 취소 이력 | 최대50단계 |

GIF는 소리가 없고 팔레트당 최대256색입니다. 반투명 PNG는 배경색에 합성한 **불투명 GIF**로 저장합니다. 지연은10ms 단위로 변환하며 매우 짧은 지연은 재생 앱에서 보정될 수 있습니다. 품질 프리셋은 크기·다음 녹화 추출 FPS·색수를 바꾸고 이미지의 표시 시간은 유지합니다.

큰 자료는 크기·FPS·구간을 줄이세요. 같은 연속 프레임 합치기는 최종 합성 픽셀이 일치하는 프레임의 시간을 합산합니다. 생성 취소 후 편집 프레임은 유지됩니다. 기기의 ‘움직임 줄이기’ 설정을 사용하면 결과 GIF는 재생 단추를 눌러 확인합니다.

## 저장과 개인정보

사진·영상·자막·변환은 브라우저 안에서 처리합니다. 서버 업로드·계정·외부 변환 API는 없습니다. Pretendard 글꼴을 읽을 때만 외부 CDN 요청이 발생합니다. 상단 채널 링크는 선택하면 외부 사이트를 엽니다.

사진·녹화는 영구 저장하지 않습니다. 새로고침·새 작업·창 닫기 전에 GIF를 저장하세요. GIF 생성 뒤 편집하면 이전 결과가 해제되어 다시 만들어야 합니다. localStorage에는 테마·레일·출력 설정만 저장합니다. 편집 프로젝트 파일 저장은 다음 버전의 확장 후보입니다.

## 단축키

| 동작 | 단축키 |
| --- | --- |
| 이미지 열기 | Ctrl/Cmd+O |
| 실행 취소 / 다시 실행 | Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z, Ctrl+Y |
| GIF 만들기 / 결과 저장 | Ctrl/Cmd+Enter / Ctrl/Cmd+S |
| 재생·정지 / 이전·다음 | Space / ←·→ |
| 선택 삭제 / 도구 선택 | Delete / 숫자1~9, 영역 녹화0 |
| 도움말 / 안내 닫기 / 레일 접기 | F1 / Esc / `[` |

단축키는 이 페이지가 활성화돼 있을 때 작동합니다. 입력칸 편집 중 재생·삭제·도구 전환 단축키는 간섭하지 않습니다.

## 파일 구성

- `index.html`: 실제 실행 파일. UI·편집·녹화·GIF 인코더를 한 파일에 포함합니다.
- `로컬실행.command`, `로컬실행.bat`: macOS·Windows localhost 실행 도우미. Python3와 `_작업자료/serve.py`를 사용합니다.
- `검증결과.md`: 실제 검사 수치와 미확인 환경.
- `라이선스.md`, `라이선스/`: 인코더·SVG·글꼴 출처와 고지.
- `_작업자료/`: 편집용 소스·조립기·인코더 고지. 검증 스크립트와 검사 산출물은 개발 환경에 보관하며 이 공개 저장소에서 제외합니다. 실행 도우미를 사용하려면 이 폴더의 `serve.py`를 함께 보관하세요. `index.html` 직접 실행에는 필요하지 않습니다.
- 기존 제작 프롬프트와 기능 조사 MD는 기획 근거로 보존했습니다. 디자인 시스템 원본은 수정하지 않았습니다.

소스 수정 후 `python3 "_작업자료/build.py"`로 HTML을 다시 조립합니다. 영상 파일·기존 GIF 가져오기, 투명 GIF·전환 효과·웹캠은 다음 버전의 확장 후보이며 비동작 단추는 두지 않았습니다.
